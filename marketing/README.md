# Studio campaign templates

Open `studio_cards.html` on a phone browser. Create vertical shorts/reels title cards, trailer end cards and thumbnails. Edit game title, headline and CTA; optionally load the approved studio logo; export PNG. No third-party services, social posting, or audio/video claims. The exported PNG can be imported into the Foxboard art editor as an image layer.

QA still needed: Android browser export, image sizing, typography and safe-area checks. This is an isolated first implementation, not yet integrated into Foxboard's main `index.html` menu.
